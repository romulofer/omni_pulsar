# Omni Pulsar

Tema de sintaxe para o [Pulsar](https://pulsar-edit.dev) baseado no
[Omni](https://github.com/rocketseat-education/omni-theme), da
[Rocketseat](https://rocketseat.com.br), originalmente feito para VS Code.
Paleta e mapeamento de cores portados fielmente a partir do
`omni.yml` original.

Este pacote cobre apenas a coloração do código (syntax theme). Sidebar,
abas, barra de status etc. seguem o tema de UI que você já usa no Pulsar.

## Instalação

Local (desenvolvimento):

```
ppm link
```

Depois, em __Settings > Themes__, selecione `Omni Pulsar` no dropdown
__Syntax Themes__.

## Créditos

Paleta e conceito original: [Omni Theme](https://github.com/rocketseat-education/omni-theme)
por Diego Fernandes, Luke Morales e João Pedro Schmitz (Rocketseat).
Licença MIT.

# Omni Pulsar (English)

Syntax theme for [Pulsar](https://pulsar-edit.dev) based on
[Omni](https://github.com/rocketseat-education/omni-theme), by
[Rocketseat](https://rocketseat.com.br), originally built for VS Code.
Palette and color mapping ported faithfully from the original `omni.yml`.

This package covers code coloring only (syntax theme). Sidebar, tabs,
status bar, etc. follow whichever UI theme you already use in Pulsar.

## Install

Local (development):

```
ppm link
```

Then, under __Settings > Themes__, pick `Omni Pulsar` from the
__Syntax Themes__ dropdown.

## Credits

Original palette and concept: [Omni Theme](https://github.com/rocketseat-education/omni-theme)
by Diego Fernandes, Luke Morales, and João Pedro Schmitz (Rocketseat).
MIT licensed.
